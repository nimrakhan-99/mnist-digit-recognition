# MNIST Digit Classification

## 📌 Project Overview
This project classifies handwritten digits from 0 to 9 using the MNIST dataset and a machine learning model.

## 🎯 Objective
The main objective of this project is to train a model that can recognize handwritten digits accurately from image data.

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- MNIST Dataset
- Kaggle Notebook

## 📊 Dataset
The project uses the **MNIST Handwritten Digit Dataset**, which contains grayscale images of handwritten digits from 0 to 9.

## 🔍 Project Workflow
1. Load the MNIST dataset
2. Preprocess and normalize the images
3. Build the machine learning model
4. Train the model
5. Evaluate model performance
6. Predict handwritten digits
7. Visualize the results

## 📈 Results
The trained model successfully learns to recognize handwritten digits from the MNIST dataset.
